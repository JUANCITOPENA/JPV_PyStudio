📦 MÓDULO 2: VARIABLES, TIPADO DINÁMICO, PARÁMETROS, INVOCACIONES Y OPERADORES
================================================================================

1. PRESENTACIÓN DIDÁCTICA:
Todo programa recibe datos de entrada, los transforma en memoria y entrega un resultado. Para lograrlo, necesitamos contenedores llamados variables, reglas sobre qué tipo de información guardan, mecanismos para pasar esos datos entre bloques de código (parámetros, paso por valor y por referencia) y operadores que permitan calcular, comparar y tomar decisiones lógicas.

2. DEFINICIÓN Y CONCEPTUALIZACIÓN:
- Variable: Es un nombre simbólico asociado a una dirección en la memoria RAM donde se almacena un objeto o valor.
- Tipado Dinámico: En Python no se declara el tipo antes de asignar el valor (`edad = 30`). El intérprete determina el tipo en tiempo de ejecución y permite que una variable cambie de tipo si se reasigna.
- Asignación e Invocación: Asignar (`=`) es vincular un valor a un nombre. Invocar (`funcion()`) es llamar o ejecutar una función o método enviándole argumentos.
- Paso por Valor vs. Paso por Referencia (En Python: Paso por Asignación de Objeto):
  * Objetos Inmutables (`int`, `float`, `str`, `tuple`): Se comportan como "paso por valor". Si los modificas dentro de una función, se crea un nuevo objeto local y la variable original fuera de la función NO cambia.
  * Objetos Mutables (`list`, `dict`, `set`): Se comportan como "paso por referencia". Si modificas sus elementos internos dentro de una función, el cambio SÍ afecta a la variable original en memoria.

3. DESGLOSE DE TIPOS DE DATOS Y TODOS LOS OPERADORES:
- Tipos de Datos Primitivos:
  * `int`: Números enteros positivos o negativos sin decimales (ej. `42`, `-10`).
  * `float`: Números reales de punto flotante con decimales (ej. `19.99`, `3.1416`).
  * `str`: Cadenas de texto Unicode entre comillas simples o dobles (ej. `"Santo Domingo"`).
  * `bool`: Valores lógicos binarios (`True` o `False`).
  * `NoneType`: Representa la ausencia intencional de valor (`None`).

- Operadores Aritméticos (Cálculos matemáticos):
  * `+` (Suma): `10 + 5` -> `15`
  * `-` (Resta): `10 - 5` -> `5`
  * `*` (Multiplicación): `10 * 5` -> `50`
  * `/` (División exacta, siempre retorna float): `10 / 4` -> `2.5`
  * `//` (División entera, descarta decimales): `10 // 4` -> `2`
  * `%` (Módulo o residuo de la división): `10 % 3` -> `1` (clave para saber si un número es par o múltiplo)
  * `**` (Potenciación): `2 ** 3` -> `8`

- Operadores de Comparación (Evalúan relaciones y retornan `True` o `False`):
  * `==` (Igual a), `!=` (Diferente de), `>` (Mayor que), `<` (Menor que), `>=` (Mayor o igual), `<=` (Menor o igual).

- Operadores Lógicos (Combinan condiciones booleanas):
  * `and`: Devuelve `True` solo si AMBAS condiciones son verdaderas.
  * `or`: Devuelve `True` si AL MENOS UNA condición es verdadera.
  * `not`: Invierte el valor lógico (`not True` es `False`).

- Operadores de Asignación Compuesta, Identidad y Pertenencia:
  * Asignación: `=`, `+=`, `-=`, `*=`, `/=`, `//=`, `%=`, `**=`.
  * Identidad: `is`, `is not` (verifican si dos variables apuntan exactamente al mismo objeto en memoria, ej. `x is None`).
  * Pertenencia: `in`, `not in` (verifican si un elemento existe dentro de una secuencia o texto).

🚦 MÓDULO 3: ESTRUCTURAS DE CONTROL (IF/ELSE, IF ANIDADO Y MATCH-CASE / SWITCH)
================================================================================

1. PRESENTACIÓN DIDÁCTICA:
Un programa sin estructuras de control sería como un tren sin cambios de vía: siempre seguiría el mismo camino sin importar lo que ocurra. Las estructuras condicionales permiten que el software analice escenarios, bifurque su ejecución y reaccione inteligentemente ante distintas entradas de datos.

2. DEFINICIÓN Y CONCEPTUALIZACIÓN:
- Condicional Simple (`if`): Ejecuta un bloque de código únicamente si la condición evaluada resulta `True`.
- Condicional Doble (`if / else`): Establece dos caminos mutuamente excluyentes: si se cumple la condición ejecuta el bloque `if`; de lo contrario, ejecuta el bloque `else`.
- Condicional Encadenado (`if / elif / else`): Evalúa múltiples condiciones secuenciales de arriba hacia abajo y ejecuta solo la primera que sea verdadera.
- Condicional Anidado (`if` dentro de otro `if`): Permite validar sub-condiciones jerárquicas (primero valida un requisito general y, solo si pasa, evalúa reglas internas más específicas).
- Selección Múltiple (`match / case` — Equivalente a `switch` en Python 3.10+): Compara una variable o patrón contra múltiples casos exactos, evitando cadenas largas de `elif` y soportando el comodín `case _:` como caso por defecto (`default`).

3. ESCENARIOS DE USO:
- Cálculo de tramos de impuestos progresivos (ISR).
- Validación de permisos de acceso por rol y estado de cuenta (activo/suspendido).
- Enrutamiento de menús de atención al cliente (IVR telefónico o chatbots) y códigos de estado HTTP (`200`, `404`, `500`).

# EJEMPLO 3: Estructura match / case (Equivalente a SWITCH) para códigos HTTP de APIs
codigo_http = 404

match codigo_http:
    case 200 | 201:
        print("✅ Éxito: La API respondió y procesó los datos correctamente.")
    case 400:
        print("⚠️ Error 400: Petición mal formada por el cliente.")
    case 401 | 403:
        print("🔐 Error de Seguridad: Token inválido o sin permisos.")
    case 404:
        print("🔍 Error 404: El recurso o endpoint solicitado no existe.")
    case 500:
        print("🔥 Error 500: Fallo interno en el servidor remoto.")
    case _:
        print(f"ℹ️ Código HTTP no catalogado: {codigo_http}")

🔄 MÓDULO 4: BUCLES E ITERACIONES (FOR, WHILE, EQUIVALENCIA DO-WHILE Y FOR ANIDADO)
================================================================================

1. PRESENTACIÓN DIDÁCTICA:
La verdadera potencia de una computadora radica en repetir millones de operaciones en fracciones de segundo sin cansarse ni cometer errores. Los bucles permiten recorrer bases de datos completas, generar reportes automáticos, validar entradas hasta que sean correctas y procesar matrices multidimensionales.

2. DEFINICIÓN Y CONCEPTUALIZACIÓN:
- Bucle `for` (For-Each / Iterador de secuencias): En Python, todo bucle `for` funciona nativamente como un `for-each`: toma una colección (`list`, `str`, `dict`, `range`) y extrae uno a uno cada elemento hasta agotarla.
- Bucle `while` (Ciclo condicional previo): Evalúa una condición ANTES de entrar al bloque. Si la condición es `False` desde el inicio, el bucle no se ejecuta ni una sola vez.
- Equivalencia de `do-while` en Python (Ciclo de ejecución mínima garantizada): Python no incluye la palabra clave `do`, pero el estándar profesional consiste en escribir `while True:` y colocar al final del bloque la validación `if condicion_salida: break`. Así se garantiza que el cuerpo del ciclo se ejecute al menos una vez antes de evaluar la salida.
- Bucle `for` Anidado: Un ciclo `for` ubicado dentro de otro ciclo `for`. Por cada iteración del ciclo externo, el ciclo interno realiza todas sus vueltas completas. Es esencial para matrices, tablas de multiplicar y cruces de datos.
- Control de Flujo Interno: `break` (detiene y sale del bucle inmediatamente) y `continue` (salta la iteración actual y pasa a la siguiente).

3. ESCENARIOS DE USO:
- Procesamiento por lotes (Batch) de miles de facturas o registros CSV.
- Menús interactivos de consola que permanecen activos hasta que el usuario elige "Salir".
- Generación de tablas matemáticas, calendarios completos y cruces de sucursales vs. meses.

# EJEMPLO 1: Bucle FOR (For-Each) con enumerate() y filtro continue
productos = list(("Monitor", "Teclado", "AGOTADO_Mouse", "Webcam"))

print("=== INVENTARIO DISPONIBLE (FOR-EACH) ===")
for indice, item in enumerate(productos, start=1):
    if "AGOTADO" in item:
        continue  # Salta los productos agotados sin detener el ciclo
    print(f"{indice}. Producto listo para venta: {item}")

# EJEMPLO 2: Bucle WHILE vs Equivalencia DO-WHILE en Python
# Parte A: WHILE tradicional (proyección de ahorro mensual)
ahorro = 1000
meses = 0
while ahorro < 3000:
    ahorro += 650
    meses += 1
print(f"WHILE: Se necesitaron {meses} meses para alcanzar RD$ {ahorro}")

# Parte B: Equivalencia DO-WHILE (se ejecuta al menos 1 vez antes de validar)
lecturas_sensor = list((45, 78, 92))
pos = 0
while True:
    valor_actual = lecturas_sensor[pos]
    print(f"DO-WHILE -> Leyendo temperatura de motor: {valor_actual}°C")
    pos += 1
    if valor_actual > 90 or pos >= len(lecturas_sensor):
        print("🚨 Alerta térmica o fin de lecturas. Deteniendo monitoreo.")
        break

# EJERCICIO REAL 2: Calculadora Exacta de Edad en Años, Meses y Días Vividos (RRHH / Salud)
# Escenario: Dada una fecha de nacimiento y la fecha actual, calcular años, meses, días exactos y días totales.
import datetime

fecha_nacimiento = datetime.date(1992, 5, 18)
fecha_actual = datetime.date(2026, 11, 26)

# Cálculo de días totales vividos
dias_totales_vividos = (fecha_actual - fecha_nacimiento).days

# Desglose exacto de años, meses y días calendario
anios = fecha_actual.year - fecha_nacimiento.year
meses = fecha_actual.month - fecha_nacimiento.month
dias = fecha_actual.day - fecha_nacimiento.day

if dias < 0:
    meses -= 1
    dias += 30  # Ajuste promedio de días del mes anterior
if meses < 0:
    anios -= 1
    meses += 12

print(f"\nEJERCICIO 2 - Fecha Nacimiento: {fecha_nacimiento} | Hoy: {fecha_actual}")
print(f"Edad exacta: {anios} años, {meses} meses y {dias} días (Total: {dias_totales_vividos:,} días vividos).")

# EJERCICIO REAL 3: Contador de Días del Año y Auditoría de Años Bisiestos en un Rango Histórico
# Escenario: Recorrer una década completa (2020-2026) calculando los días exactos de cada año.
total_dias_periodo = 0

print("\nEJERCICIO 3 - AUDITORÍA DE DÍAS POR AÑO (2020 - 2026):")
for anio_eval in range(2020, 2027):
    es_bisiesto = (anio_eval % 4 == 0 and anio_eval % 100 != 0) or (anio_eval % 400 == 0)
    dias_del_anio = 366 if es_bisiesto else 365
    total_dias_periodo += dias_del_anio
    etiqueta = "Bisiesto" if es_bisiesto else "Normal  "
    print(f"   Año {anio_eval} [{etiqueta}] -> {dias_del_anio} días")

print(f"Total de días transcurridos en el periodo analizado: {total_dias_periodo:,} días.")

🗂️ MÓDULO 5: ESTRUCTURAS DE DATOS (LISTAS, ARRAYS, TUPLAS, SETS, DICCIONARIOS Y MATRICES)
================================================================================

1. PRESENTACIÓN DIDÁCTICA:
Cuando trabajamos con cientos o millones de registros, crear variables sueltas (`cliente1`, `cliente2`...) es imposible. Las estructuras de datos organizan colecciones de información en memoria con reglas específicas de orden, mutabilidad y velocidad de búsqueda.

2. DEFINICIÓN, CONCEPTUALIZACIÓN Y ESCENARIOS DE USO DE CADA ESTRUCTURA:
- Lista (`list`): Secuencia ordenada, indexada desde 0 y mutable (`[10, 20, 30]`). Permite duplicados y mezclar tipos. Escenario: Carrito de compras, cola de tareas, historial dinámico.
- Array (`array.array` / `numpy.ndarray`): Estructura contigua en memoria que almacena elementos de un ÚNICO tipo numérico homogéneo. Consume hasta 70% menos RAM que una lista y opera a velocidad de lenguaje C. Escenario: Procesamiento de señales, sensores IoT y vectores matemáticos.
- Tupla (`tuple`): Secuencia ordenada e INMUTABLE (`(18.48, -69.93)`). Una vez creada no se puede alterar, lo que protege datos críticos y acelera su lectura. Escenario: Coordenadas GPS, registros devueltos por una consulta SQL, claves compuestas.
- Conjunto (`set`): Colección desordenada de elementos ÚNICOS sin duplicados (`{"RD", "US", "ES"}`). Permite operaciones matemáticas de conjuntos (unión, intersección, diferencia) en tiempo constante $O(1)$. Escenario: Deduplicación masiva de correos o cédulas, comparación de permisos entre usuarios.
- Diccionario (`dict`): Estructura asociativa de pares `clave: valor` (`{"id": 101, "nombre": "Ana"}`). Las claves son únicas e inmutables y permiten búsquedas instantáneas. Escenario: Respuestas de APIs REST (JSON), perfiles de usuario, catálogos indexados.
- Matriz (Lista bidimensional / Matriz NumPy): Tabla organizada en filas y columnas (`matriz[fila][columna]`). Escenario: Tableros de control, imágenes digitales (píxeles), horarios semanales y álgebra lineal.

# EJERCICIO REAL 2: Motor de Inventario y Valorización de Almacén con Diccionarios (ERP)
# Escenario: Calcular el valor total del inventario y detectar productos con stock crítico (< 5 unidades).
inventario = {
    "SKU-01": {"nombre": "Router WiFi 6", "precio": 120.0, "stock": 14},
    "SKU-02": {"nombre": "Cable UTP Cat6", "precio": 45.0, "stock": 3},
    "SKU-03": {"nombre": "Servidor NAS", "precio": 680.0, "stock": 2}
}

valor_total_almacen = 0.0
print("\nEJERCICIO 2 - REPORTE DE INVENTARIO:")
for sku, info in inventario.items():
    subtotal_sku = info["precio"] * info["stock"]
    valor_total_almacen += subtotal_sku
    alerta = "⚠️ REORDENAR" if info["stock"] < 5 else "✅ OK"
    print(f"   [{sku}] {info['nombre']:16s} | Stock: {info['stock']:2d} | Valor: US$ {subtotal_sku:7.2f} | {alerta}")

print(f"Valorización total del almacén: US$ {valor_total_almacen:,.2f}")

# EJERCICIO REAL 3: Análisis de Matriz de Ventas por Sucursal y Trimestre (Business Intelligence)
# Escenario: Sumar ventas por fila (sucursal) y por columna (trimestre) sobre una matriz 3x4.
sucursales_nombres = list(("Santo Domingo", "Santiago", "Punta Cana"))
ventas_trimestrales = list((
    list((150, 180, 210, 250)),  # Santo Domingo (Q1, Q2, Q3, Q4)
    list((110, 130, 145, 170)),  # Santiago
    list((140, 190, 220, 260))   # Punta Cana
))

print("\nEJERCICIO 3 - CONSOLIDADO ANUAL POR SUCURSAL:")
for i, sucursal in enumerate(sucursales_nombres):
    total_sucursal = sum(ventas_trimestrales[i])
    print(f"   {sucursal:15s} -> Total Anual: US$ {total_sucursal}K")

totales_por_trimestre = list((sum(fila[col] for fila in ventas_trimestrales) for col in range(4)))
print("   Totales por Trimestre (Q1 a Q4 en miles):", totales_por_trimestre)
