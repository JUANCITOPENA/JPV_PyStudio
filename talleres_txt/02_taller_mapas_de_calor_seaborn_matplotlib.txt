
🔥 RETO #1: VISUALIZA DATOS COMO UN ANALISTA DE DATOS

En este proyecto utilizamos Python junto con las librerías Seaborn y Matplotlib para transformar una matriz numérica en un mapa de calor. Este tipo de gráfico permite identificar rápidamente valores altos y bajos mediante colores, facilitando el análisis visual sin necesidad de revisar cada número manualmente.

La instrucción `import seaborn as sns` carga la librería especializada en visualización de datos. La instrucción `import matplotlib.pyplot as plt` permite mostrar y personalizar gráficos. Finalmente, `sns.heatmap(datos, annot=True)` genera el mapa de calor mostrando los valores dentro de cada celda, mientras que `plt.show()` presenta el resultado en pantalla.

import seaborn as sns
import matplotlib.pyplot as plt

# 1. Datos básicos (una matriz de 3x3)
datos = [
    [10, 20, 30],
    [40, 50, 60],
    [70, 80, 90]

# 3. Mostrar el gráfico en pantalla

🔥 RETO #2: DESCUBRE EL MEJOR MOMENTO PARA VENDER

En este ejercicio utilizamos Python, Pandas, Seaborn y Matplotlib para analizar ventas semanales organizadas por días y turnos. El objetivo es convertir una tabla de datos en una visualización capaz de revelar oportunidades de negocio con un simple vistazo.

La instrucción `import pandas as pd` permite crear estructuras tabulares para el análisis de datos. Mediante `pd.DataFrame()` se construye la tabla de ventas. Luego, `sns.heatmap(tabla_ventas, annot=True, fmt="d", cmap="YlGnBu")` transforma la información en un mapa de calor utilizando una escala de colores avanzada. La función `plt.title()` agrega un título al gráfico y `plt.show()` despliega el resultado final.

🚀 ¿Por qué esto importa?

Estas mismas técnicas son utilizadas por Data Analysts, Data Engineers, Científicos de Datos y especialistas en Business Intelligence para encontrar patrones, detectar anomalías y apoyar la toma de decisiones basadas en datos. Lo que para una persona son cientos de números, para un mapa de calor se convierte en información visual lista para interpretar en segundos.




import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

# 1. Creamos la tabla usando paréntesis para evitar errores de copiado
datos = {
    'Lunes': list((150, 300, 200)),
    'Martes': list((180, 320, 250)),
    'Miércoles': list((200, 400, 300)),
    'Jueves': list((220, 380, 350)),
    'Viernes': list((300, 500, 600))
}

# Ponemos nombre a las filas (los turnos)
tabla_ventas = pd.DataFrame(datos, index=list(('Mañana', 'Tarde', 'Noche')))

# 2. Creamos el mapa de calor
sns.heatmap(tabla_ventas, annot=True, fmt="d", cmap="YlGnBu")

# 3. Agregamos título y mostramos el gráfico
plt.title("Ventas semanales por turno ($)")
plt.show()



🔥 RETO #3: RADAR CLIMÁTICO — ¿QUÉ DÍA HACE MÁS CALOR?

En este proyecto utilizamos Python, Pandas, Seaborn y Matplotlib para analizar las temperaturas registradas durante toda una semana en distintas zonas de una ciudad (por ejemplo, Santo Domingo, Santiago y Punta Cana). Este tipo de visualización permite detectar olas de calor y comparar microclimas con un solo vistazo, sin necesidad de leer filas interminables de reportes meteorológicos.

La instrucción fmt=".1f" indica a Seaborn que muestre los valores con un decimal exacto (ideal para mediciones científicas o climáticas). Por su parte, la paleta cmap="YlOrRd" (Amarillo → Naranja → Rojo intenso) asocia intuitivamente los tonos cálidos con las temperaturas más extremas, mientras que linewidths=1 dibuja líneas blancas entre celdas para separar visualmente cada día.

🎬 Reto para el video: Observa el mapa de calor de temperaturas y determina en menos de 5 segundos cuál es el día más caluroso de la semana y en qué ciudad se registró el pico máximo. ¿Puedes notar qué ciudad mantiene el clima más fresco en promedio solo mirando los tonos amarillos?

🚀 ¿Por qué esto importa?

Los ingenieros ambientales, empresas de energía y plataformas de logística utilizan mapas de calor térmicos para predecir picos de consumo eléctrico (por uso de aires acondicionados) y proteger cadenas de suministro sensibles al calor.

import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

# 1. Temperaturas promedio (°C) por día y ciudad
datos_clima = {
    'Lun': list((31.2, 29.5, 30.0)),
    'Mar': list((32.0, 30.1, 30.8)),
    'Mié': list((33.5, 31.0, 31.5)),
    'Jue': list((34.8, 32.4, 32.1)),
    'Vie': list((33.9, 31.8, 31.9)),
    'Sáb': list((32.5, 30.5, 31.2)),
    'Dom': list((31.8, 29.8, 30.4))
}

tabla_clima = pd.DataFrame(datos_clima, index=list(('Santo Domingo', 'Santiago', 'Punta Cana')))

# 2. Creamos el mapa de calor con formato decimal (.1f) y bordes
sns.heatmap(tabla_clima, annot=True, fmt=".1f", cmap="YlOrRd", linewidths=1)

# 3. Personalizamos títulos y etiquetas
plt.title("Temperatura Máxima Semanal (°C)")
plt.xlabel("Día de la Semana")
plt.ylabel("Ciudad")
plt.show()

🔥 RETO #7 (NIVEL MAESTRO): MAPA DE CALOR 24/7 CON NUMPY — CIBERSEGURIDAD Y TRÁFICO WEB

En este desafío damos el salto a la ciencia de datos a gran escala. En lugar de escribir los números manualmente, utilizamos la librería NumPy para simular una matriz completa de 168 datos (24 horas del día × 7 días de la semana), representando el tráfico de conexiones o intentos de acceso a un servidor en la nube.

La función np.random.randint() genera datos aleatorios controlados, mientras que annot=False apaga los números dentro de los cuadros (porque en matrices grandes los números ensucian la vista y lo importante es el patrón visual). Además, cmap="magma" aplica una paleta térmica de alto contraste usada en ingeniería y ciberseguridad para detectar anomalías nocturnas.

🎬 Reto para el video: Analiza este radar de 24 horas durante toda la semana sin mirar ni un solo número. ¿Puedes detectar exactamente en qué horario se produce el pico máximo de tráfico y si existe alguna actividad sospechosa en la madrugada?

🚀 ¿Por qué esto importa?

Los ingenieros de infraestructura (Cloud/DevOps) y analistas de ciberseguridad monitorean matrices 24/7 en tiempo real para detectar ataques informáticos (DDoS) en la madrugada o programar mantenimientos de servidores en las horas de menor actividad sin afectar a los usuarios.

import numpy as np
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

# 1. Simulamos 24 horas x 7 días con NumPy (168 puntos de datos)
np.random.seed(42)  # Fija los datos para que siempre salgan igual en tu video
trafico = np.random.randint(20, 80, size=(24, 7))

# Simulamos un pico de tráfico en horario laboral (9 AM a 6 PM) de Lunes a Viernes
trafico[9:18, 0:5] += np.random.randint(60, 120, size=(9, 5))

# Simulamos una anomalía sospechosa el Sábado a las 3:00 AM
trafico[3, 5] = 210

# Convertimos la matriz en un DataFrame con horas y días
dias = list(('Lun', 'Mar', 'Mié', 'Jue', 'Vie', 'Sáb', 'Dom'))
horas = list((f"{h:02d}:00" for h in range(24)))
tabla_servidor = pd.DataFrame(trafico, index=horas, columns=dias)

# 2. Mapa de calor 24/7 (sin números internos para priorizar el patrón visual)
plt.figure(figsize=(9, 7))
sns.heatmap(
    tabla_servidor, 
    annot=False, 
    cmap="magma", 
    cbar_kws={'label': 'Peticiones por Segundo'}
)

# 3. Títulos y formato
plt.title("Monitor de Tráfico de Servidor 24/7 (Detección de Anomalías)", fontweight='bold')
plt.xlabel("Día de la Semana")
plt.ylabel("Hora del Día")
plt.tight_layout()
plt.show()




🏆 BONUS EJECUTIVO: DASHBOARD 2x2 EN UNA SOLA PANTALLA

En este proyecto final combinamos Clima, Tienda, Streaming y Hospital dentro de una sola figura dividida en 4 cuadrantes usando plt.subplots(2, 2). Esta es la estructura base para crear reportes ejecutivos automatizados en Python.
La variable axes funciona como una cuadrícula de coordenadas (axes[0, 0] arriba a la izquierda, axes[0, 1] arriba a la derecha, axes[1, 0] abajo a la izquierda y axes[1, 1] abajo a la derecha), permitiendo renderizar múltiples mapas de calor con distintas paletas de colores simultáneamente.

import matplotlib.pyplot as plt

dias = list(('Lun', 'Mar', 'Mié', 'Jue', 'Vie', 'Sáb', 'Dom'))

    'Lun': list((31, 29, 30)), 'Mar': list((32, 30, 31)), 'Mié': list((34, 31, 32)),
    'Jue': list((35, 32, 32)), 'Vie': list((34, 32, 32)), 'Sáb': list((33, 31, 31)), 'Dom': list((32, 30, 30))

df_hospital = pd.DataFrame({
    'Lun': list((12, 35, 25)), 'Mar': list((10, 30, 22)), 'Mié': list((14, 32, 28)),

🎯 RETO #3: SEGMENTACIÓN DE 75 CLIENTES DISPERSOS CON IA (CLUSTERING K-MEANS)

En este proyecto aplicamos Machine Learning no supervisado (KMeans) junto con NumPy, Pandas, Seaborn y Matplotlib para segmentar automáticamente una cartera simulada de 75 clientes dispersos, cruzando su frecuencia de compra mensual, su gasto acumulado y su método de pago preferido (Efectivo, Tarjeta o Transferencia).


import numpy as np
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans

# Fijamos la semilla para que los puntos dispersos salgan siempre igual
np.random.seed(42)

# 1. Generamos 75 clientes bien dispersos (25 por cada grupo)
# Grupo A: Frecuencia baja (1 a 6) y Gasto bajo ($30 a $280)
frec_a = np.random.uniform(1, 6, 25).round(1)
gasto_a = np.random.uniform(30, 280, 25).round(0)
pago_a = np.random.choice(list(('Efectivo', 'Tarjeta')), size=25, p=list((0.75, 0.25)))

# Grupo B: Frecuencia media (7 a 14) y Gasto medio ($400 a $900)
frec_b = np.random.uniform(7, 14, 25).round(1)
gasto_b = np.random.uniform(400, 900, 25).round(0)
pago_b = np.random.choice(list(('Tarjeta', 'Efectivo', 'Transferencia')), size=25, p=list((0.70, 0.15, 0.15)))

# Grupo C: Frecuencia alta (15 a 25) y Gasto alto ($1,050 a $2,000)
frec_c = np.random.uniform(15, 25, 25).round(1)
gasto_c = np.random.uniform(1050, 2000, 25).round(0)
pago_c = np.random.choice(list(('Transferencia', 'Tarjeta')), size=25, p=list((0.80, 0.20)))

# Unimos todo en una sola tabla
clientes_ventas = pd.DataFrame({
    'Frecuencia_Mes': np.concatenate(list((frec_a, frec_b, frec_c))),
    'Gasto_Total_USD': np.concatenate(list((gasto_a, gasto_b, gasto_c))),
    'Tipo_Pago': np.concatenate(list((pago_a, pago_b, pago_c)))
})

# 2. Entrenamos el modelo K-Means
variables_numericas = clientes_ventas.loc[:, list(('Frecuencia_Mes', 'Gasto_Total_USD'))]
modelo = KMeans(n_clusters=3, random_state=42, n_init=10)
clusters_num = modelo.fit_predict(variables_numericas)

# Ordenamos los clusters por gasto promedio para asignar Cliente A, B y C
orden_gasto = pd.Series(clientes_ventas.get('Gasto_Total_USD')).groupby(clusters_num).mean().sort_values().index
nombres_clientes = list(('Cliente A', 'Cliente B', 'Cliente C'))
mapa_etiquetas = dict(zip(orden_gasto, nombres_clientes))

clientes_ventas['Segmento'] = pd.Series(clusters_num).map(mapa_etiquetas)

print(f"🎯 TOTAL DE CLIENTES ANALIZADOS: {len(clientes_ventas)}")
print(clientes_ventas.value_counts('Segmento'))

# 3. Gráfico amplio y disperso
plt.figure(figsize=(11, 6))
sns.scatterplot(
    data=clientes_ventas,
    x='Frecuencia_Mes',
    y='Gasto_Total_USD',
    hue='Segmento',
    hue_order=nombres_clientes,
    style='Tipo_Pago',
    palette='Set1',
    s=130,
    edgecolor='black',  # Borde fino en cada figura para distinguirlos aún mejor
    alpha=0.9
)

plt.title("Clustering de 75 Clientes Dispersos: Frecuencia, Gasto y Tipo de Pago", fontweight='bold')
plt.xlabel("Frecuencia de Compra (Promedio Mensual)")
plt.ylabel("Gasto Mensual Acumulado ($ USD)")
plt.grid(True, linestyle='--', alpha=0.4)
plt.legend(bbox_to_anchor=(1.02, 1), loc='upper left')
plt.tight_layout()
plt.show()
